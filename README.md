# PolicyAthena---frontend
This is the frontend of the PolicyAthena project, built with **React**, **Vite**, **Tailwind CSS**, and **ShadCN/UI** components.

## Installation
1. Clone the repository: 
```
git clone <repository_url>
```
2. Install dependencies

```
npm install
```
3. Start the development server

```
npm run dev
```
4. Access ui:
- Navigate to `http://localhost:5173` in your browser to access the UI

### Notes
1. Do NOT run npx shadcn-ui@latest init again. All necessary components and setup are already included in the codebase.

2. Make sure Node.js 18+ installed. Use 
```
node -v
```
to check your local node version. 

3. If using VS Code, it's recommended to install the "Tailwind CSS IntelliSense" extension for a better development experience.
